A sentence that talks about itself

Kerem Zengin · 4 November 2026

Draft. A short tour of self-reference: a liar sentence, a loop drawn for this page, and a program that prints its own source. Nothing here is a proof.

TL;DR

Most sentences talk about something else. A self-referential one talks about its own text. That single turn is enough to make a sentence that cannot sit still as true or false, and enough to write a program whose output is a copy of the program.

Assign a truth value

The sentence below says of itself that it is false. Pick a value. The note under it is what that choice forces. This is the liar paradox in one line. It is not a puzzle with a hidden third answer on this page.

Two drawers

The picture on the blog index is Escher’s Drawing Hands: each hand is drawn by the other. The drawing here is a stand-in, not a copy of that print. Two boxes. Each arrow says the box it leaves is what draws the box it enters. Follow either arrow and you are back where you started. Douglas Hofstadter’s name for this kind of climb that returns to its start is a strange loop.

A program that prints itself

A quine is a program whose output is its own source. The usual trick is a template with a hole. The template says: fill the hole with a quoted copy of me. Press the button and the hole is filled. The text of the program and the text it prints are the same string. Nothing is executed beyond that fill.
